# Support

Looking for help with Astro-Mine? Here is where to go:

- **Questions & discussion** — GitHub Discussions, once enabled. They cannot be turned on
  usefully while the organization is private, so until then open an issue and label it a question.
- **Bug reports & feature requests** — open an issue on the repository that ships the code, using
  the provided templates: **`astro-mine-platform`** (any component's library code),
  **`astro-mine-cli`**, **`astro-mine-api`**, **`astro-mine-ui`**, or **`docs`**. There is no
  per-component repository — a new component is a subpackage of the platform wheel.
- **Security issues** — do **not** open a public issue; follow the
  [Security Policy](SECURITY.md).
- **Design proposals / changes to `Core`** — open an issue on the relevant repository, and
  see [how changes are governed](GOVERNANCE.md#how-changes-are-governed) for what a Core
  change has to clear.

During incubation, response times are best-effort. Thanks for your patience as the project gets
off the ground.
