# `.github` — Astro-Mine org defaults

This repository holds organization-wide defaults for [`astro-mine`](https://github.com/astro-mine):

- **`profile/README.md`** — the public organization landing page.
- **Community-health defaults** inherited by every repo that doesn't define its own:
  `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `GOVERNANCE.md`,
  `EXPORT_CONTROL.md`.
- **`.github/`** — shared issue forms and the pull-request template.
- **`rfcs/`** — the RFC process and its template (`0000-template.md`).

Edit these here and the change propagates across the organization.
